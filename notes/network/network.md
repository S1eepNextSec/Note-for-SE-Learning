# Network

## Application Layer

应用层主要协议有HTTP、FTP等。应用层实际上与网络本身不相关，只是进行了数据如何显示渲染的规定和约束，与数据如何进行端到端的传输并不相关。

## Transport Layer

传输层关心在网络的一端到另一端如何建立连接。如果网络的一端每次只能建立其一个到网络中其他端的连接，那么效率会很低。为了能够同时与多个网络中其他的机器建立起连接，于是采用了**端口**的概念。比如说在一台机器上最多有65535个端口，如果要与网络中其他机器进行连接，就必须选择一个端口来使用，这个端口就相当于一个个虚拟的、逻辑上的“插槽”。端口本身是一个有限的资源，他使网络建立多个连接成为可能，但是也意味着最多能建立的连接数有限制。

传输层的协议包括TCP & UDP等协议。

## Network Layer

网络层主要关心如何从一个机器在网络中找到一条路径到达另一台机器。

网络层由许多实际的网络相关的机器构成，由这些机器构建起网络层，通过IP来定位网络中的机器。
